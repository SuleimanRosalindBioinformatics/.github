## 🌟 Təşkilatın Missiyası (Organization Mission)

**SuleimanRosalindBioinformatics** — [Rosalind.info](http://rosalind.info/) platformasında dərc edilmiş **bütün 284 bioinformatika probleminin** optimal, akademik səviyyəli həllərini, nəzəri riyazi modelləşdirməsini və brauzer-yerli interaktiv alqoritm laboratoriyasını cəmləşdirən mərkəzi elmi-tədqiqat və tədris ekosistemidir.

Layihə biologiya ilə nəzəri kompüter elmlərinin kəsişməsində yerləşən ən mürəkkəb alqoritmik sahələri sıfırdan həll edir:
1. **Dinamik Proqramlaşdırma:** Qlobal və lokal zəncir düzləndirməsi, Affine gap cəzaları, Hirschberg xətti yaddaş alqoritmi ($O(|v|+|w|)$).
2. **Genom Yığılması:** De Bruijn qrafları, Eulerian dövr və yolları, k-mer spektrləri və qoşa oxunuşlardan de novo yığılma.
3. **Stoxastik Modellər və Gizli Markov Modelləri (HMM):** Viterbi dekodlaşdırması, Forward-Backward alqoritmi, Baum-Welch parametr öyrənməsi və Profil HMM-lər.
4. **Filogenetika:** Additiv filogeniya, UPGMA, Neighbor-Joining, Small & Large Parsimony ağac axtarışı.
5. **Kütlə Spektrometriyası:** De novo peptid sekvensləşdirməsi, spektral konvolyusiya və PSM lüğətlərinin qurulması.

## 🧠 Çarpaz Alqoritmik Sintezlər və Alətlər (LLM Wiki Sprints)

Bilik bazası sadəcə məsələlərin kataloqu deyil; o, alqoritmlər arasında riyazi və struktur əlaqələri quran dayanıqlı **LLM Wiki** sintezlərindən ibarətdir:

1. ⚡ **[Dynamic Programming Alignment Paradigms](https://github.com/SuleimanRosalindBioinformatics/SuleimanRosalindBioinformatics/blob/main/wiki/dynamic-programming-alignment-paradigms.md):** 7 əsas düzləndirmə modelinin (Global, Local, Fitting, Overlap, Semiglobal, Affine Gaps, Hirschberg Linear Space $O(n+m)$) rekurrent tənlikləri və müqayisəli taksonomiyası.
2. 🧬 **[Genome Assembly Paradigms](https://github.com/SuleimanRosalindBioinformatics/SuleimanRosalindBioinformatics/blob/main/wiki/genome-assembly-paradigms-comparative.md):** OLC (Hamiltonian, NP-complete) yanaşmasından De Bruijn qraflarına (Eulerian, linear $O(V+E)$) keçid və qoşa oxunuşlu $(k, d)$-mer gapped yığılma.
3. 📊 **[Complexity & Asymptotic Bounds Matrix](https://github.com/SuleimanRosalindBioinformatics/SuleimanRosalindBioinformatics/blob/main/wiki/algorithmic-complexity-and-bounds-matrix.md):** 284 məsələnin asimptotik zaman ($O(n), O(n \log n), O(nm), O(n^3)$) və yaddaş mürəkkəblik matrisi.
4. 🎲 **[Hidden Markov Models in Computational Biology](https://github.com/SuleimanRosalindBioinformatics/SuleimanRosalindBioinformatics/blob/main/wiki/hidden-markov-models-in-computational-biology.md):** Üç fundamental HMM probleminin (Evaluation, Viterbi Decoding, Baum-Welch EM) və Profil HMM arxitekturasının unifikasiyası.
5. 🔍 **[tools/search_wiki.py](https://github.com/SuleimanRosalindBioinformatics/SuleimanRosalindBioinformatics/blob/main/tools/search_wiki.py):** Bütün Markdown bilik bazası üzərində BM25 reytinqli sürətli yerli CLI axtarış mühərriki.

## 💻 Lokal Quraşdırma və İcra / Local Development

Repozitoriyanı lokal kompüterinizə klonlamaq və həlləri icra etmək üçün:

```bash
# 1. Əsas kod reposunu klonlayın
git clone https://github.com/SuleimanRosalindBioinformatics/SuleimanRosalindBioinformatics.git
cd SuleimanRosalindBioinformatics

# 2. İstənilən məsələ qovluğuna daxil olub Python 3 ilə icra edin
python3 "Align Two Strings Using Linear Space/main.py"
```

Canlı veb-portal layihəsini lokal kompüterdə önizləmək üçün:

```bash
# Veb-portal reposunu klonlayın
git clone https://github.com/SuleimanRosalindBioinformatics/SuleimanRosalindBioinformatics.github.io.git
cd SuleimanRosalindBioinformatics.github.io

# Lokal veb-server başladın
python3 -m http.server 8000
```
Brauzerinizdə `http://localhost:8000` ünvanını açın.
