## Reporting a Vulnerability

If you discover a security vulnerability, sensitive data leakage, or malicious code pattern within any repository of the SuleimanRosalindBioinformatics organization, please do **NOT** open a public issue.

Instead, please send a private email directly to the maintainer:
📧 **suleyman.hacizade1@gmail.com**

Please include:
* Repository name and commit hash where the vulnerability resides.
* Detailed steps to reproduce or proof of concept.
* Potential biological data, server, or client security impact.

We take security reports with high priority and will acknowledge receipt within 48 hours.
